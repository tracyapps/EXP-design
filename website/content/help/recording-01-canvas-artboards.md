## Draft page: Create and organize artboards

**Summary:** A new EXP document begins with an artboard ready to use. Resize it,
add common sizes, duplicate it with its contents, and arrange several artboards
into a working flow.

### Resize an artboard

1. Select the artboard on the canvas or in Layers.
2. Drag a corner or edge handle to resize it visually.
3. For an exact size, enter its width and height in Properties.
4. When changing a numeric value with the keyboard, hold Shift to move in
   increments of 10.

### Add an artboard from a preset

Open the artboard preset menu and choose a phone, tablet, desktop, web, or paper
size. EXP places the new artboard beside the existing one, where you can resize
or reposition it.

### Duplicate an artboard

Hold Option while dragging an artboard. A plus sign appears beside the pointer
to show that you are creating a copy. Hold Shift as well to keep the copy aligned
with the original.

Objects on the artboard are duplicated with it, making this useful for creating
the next screen or variation in a flow.

### Rename an artboard

Rename an artboard from whichever part of the interface is convenient:

- Double-click its title above the artboard.
- Double-click its name in Layers.
- Edit its name in Properties.

The new name updates everywhere.

### Move one or several artboards

Drag an artboard by its title to move it. To rearrange several artboards
together, drag a selection rectangle that fully encloses them, then drag any
selected artboard to move the set.

### Delete an artboard

Select one or more artboards and press Delete. Deleting an artboard also deletes
the objects it contains. Choose Edit > Undo or press Command-Z if you remove one
by mistake.

## Draft page: Use the wall as a thinking space

**Summary:** The area around your artboards is the wall. Use it to keep labels,
visual references, loose ideas, and project context near the work without
forcing everything into an artboard.

### Organize work into visible areas

1. Move related artboards near one another.
2. Add a large text label to name the area, such as **Wireframes**, **Branding**,
   or **Exploration**.
3. Place reference shapes, colors, images, or notes nearby.
4. Move the whole cluster to a comfortable part of the wall as the document
   grows.

The same Option-drag gesture used elsewhere in EXP duplicates objects on the
wall. This makes it easy to repeat labels, swatches, or other reference material.

There is no required wall structure. Treat it as working space: keep only the
context that helps you design and understand the project.

## Draft page: Pan and zoom around the canvas

**Summary:** Navigate EXP with trackpad gestures, the Pan tool, or the zoom
controls in the toolbar.

### Use a trackpad

- Pinch to zoom in or out.
- Move two fingers to pan across the wall.

### Use the Pan tool

Select the Pan tool, then drag anywhere on the canvas to move the view without
moving an artboard or object.

### Set the zoom level

Use the zoom-in and zoom-out controls in the toolbar for quick changes. Open the
zoom menu to choose a common percentage such as 50% or 100%, or enter a custom
percentage when you need a specific view.

## Draft page: Show the document grid and snap to it

**Summary:** The document grid covers the wall and artboards with an evenly
spaced reference. Turn on snapping when objects should land directly on its
lines.

### Configure the grid

1. Click an empty area of the wall so nothing is selected.
2. In Properties, turn on **Show grid**.
3. Set the grid size and number of subdivisions. Hold Shift while changing a
   numeric value to move in increments of 10.
4. Turn on **Snap to grid** when objects should align to the grid as they move.

The same Show Grid and Snap to Grid commands are available in the View menu,
along with their keyboard shortcuts.

Turn off Show Grid when you want an unobstructed view. Its size and subdivision
settings remain available the next time you show it.

## Draft page: Add layout grids to an artboard

**Summary:** Layout grids belong to an individual artboard. Add column, row, or
baseline overlays to guide composition and text alignment, and combine more than
one grid when the design needs it.

### Add a layout grid

1. Select an artboard.
2. In Properties, find **Layout grids** and choose the add control.
3. Choose Columns, Rows, or Baseline.

### Configure columns or rows

For a column or row grid, adjust the count, gutter, and margin. EXP updates the
overlay immediately as you change each value.

### Configure a baseline grid

Use a baseline grid as a repeated alignment reference for text and other
elements. Change the grid color when several overlays need to remain visually
distinct.

### Hide, combine, or remove grids

- Turn off a grid’s checkbox to hide it without losing its settings.
- Add multiple grids when you need to compare systems or combine columns, rows,
  and baselines.
- Choose the remove control beside a grid to delete it from the artboard.

Layout grids can be shown or hidden independently, so you can keep a system in
the document without displaying every overlay at once.
