A page the importer has never seen

Two cards, one breakpoint

Side by side above 768px

Below the breakpoint these stack, and the padding shrinks. That is the only thing the media query does, so the difference between the two imported viewports should be exactly this and nothing else.

Gradient, radius, shadow

This card carries a linear-gradient background, a border radius, and a box-shadow, so the paint and effect mapping has something to report.

Type that must be measured, not re-laid-out

Deliberately long enough to wrap differently at 393pt than it does at 1440pt, with a hanging word or two, so that a viewport whose line breaks were re-computed rather than measured will disagree visibly with the browser instead of failing quietly.

An external link that must map to a link role, and bold plus italic runs inside one paragraph so text-run splitting is exercised.

No data-exp-id anywhere in this file. That is the point.
